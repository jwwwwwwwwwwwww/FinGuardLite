# FinGuard Lite

FinGuard Lite is a student-built fintech risk monitoring prototype that simulates transaction screening, risk alert review, and audit traceability.

I built this project during my break to connect what I am learning in fintech, application development, risk monitoring, and compliance into one working system.

## Project Purpose

In a real financial institution, transaction data would usually be ingested from banking, card, payment, or AML monitoring systems.

Since this is a student portfolio prototype without access to real banking data, FinGuard Lite uses mock customer profiles and simulated transactions to demonstrate how an internal transaction risk monitoring workflow could work.

The project is not meant to be a production fraud detection or AML system. It is a learning prototype focused on application logic, risk scoring, alert review, and audit traceability.

## Features

- Role-based login for Risk Analyst, Compliance Officer, and Admin
- Mock customer profile management
- Simulated transaction records
- Rule-based transaction risk scoring
- Automatic risk alert generation
- Alert review workflow
- Audit logs for traceability
- Dashboard showing transaction and risk overview
- Five-year mock dataset from 2022 to 2026

## Risk Scoring Rules

The prototype uses simple rule-based checks to calculate a transaction risk score.

Examples of rules include:

- High transaction amount
- Very high transaction amount
- Overseas transaction
- Unknown merchant
- High-risk category such as Crypto, Gambling, Unknown, or Money Transfer
- Transaction amount exceeding 50% of customer's monthly income
- Repeated transactions by the same customer in one day

Transactions with medium or high risk scores are flagged as risk alerts.

## Dataset

The application uses mock data generated by a database seeder.

The sample dataset includes:

- Mock customer profiles
- Simulated transactions from 2022 to 2026
- Generated risk alerts
- Audit log records

No real financial, banking, or personal customer data is used.
